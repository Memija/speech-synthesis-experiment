# Speech Synthesis Experiment

A web application that demonstrates the use of the **Web Speech API** for speech synthesis. Users can input text, select different voices, and adjust parameters like pitch, rate, and volume to customize the speech output.

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=Memija_speech-synthesis-experiment&metric=alert_status)](https://sonarcloud.io/dashboard?id=Memija_speech-synthesis-experiment)

## Features

- **Voice Selection:** Choose from a list of available system voices.
- **Pitch Control:** Adjust the pitch of the speech (0 to 2).
- **Rate Control:** Adjust the speed of the speech (0 to 10).
- **Volume Control:** Adjust the volume of the speech (0 to 1).
- **Text Input:** Type or paste any text you want to be spoken.
- **Start/Stop Controls:** Buttons to start the speech or stop it at any time.

## Technologies Used

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **Bootstrap 5** (for styling and responsiveness)

## Getting Started

### Prerequisites

You need a modern web browser that supports the Web Speech API (e.g., Chrome, Firefox, Edge, Safari).

### Running the Application

1. Clone the repository:
   ```bash
   git clone https://github.com/Memija/speech-synthesis-experiment.git
   ```
2. Navigate to the project directory:
   ```bash
   cd speech-synthesis-experiment
   ```
3. Open `index.html` in your web browser.

### Development

To install dependencies and run tests:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run tests:
   ```bash
   npm test
   ```
